Summarize the user's BEHAVIORAL HABITS from the pre-fetched habit profiles
(作息规律) and activity data in the Context. This is about WHEN and HOW the user
works in a repeatable way — daily rhythm, focus vs. fragmentation, tool routines
— not a log of one day's events.

Read the DeskMate skill first.

Ground every claim in the data; the 作息规律 block already encodes when/what.
If a section lacks evidence, say so briefly instead of inventing it. Use this
exact format:

## 一句话总结
One sentence: the user's overall work rhythm and style.

## 日常作息
- The repeatable weekday vs. weekend pattern: when they start, peak hours, and
  what category dominates each part of the day. Cite the 作息规律 slots
  (day_type · time · category · frequency).

## 专注与节奏
- Focus depth vs. context-switching: long sessions in one app vs. frequent
  switching. Use per-app minutes and how many apps/windows appear — never invent
  durations.

## 常用工具链
- The tools the user relies on, grouped by purpose (开发 / 浏览 / 沟通 / 系统),
  with the time share from the Apps section.

## 值得注意的习惯
- 2–4 noteworthy or improvable habits (e.g. late-night work, heavy
  context-switching, a dominant single tool). Be specific and evidence-based.

## 数据说明
- One line on coverage: the window analyzed and any gap (e.g. "录制天数较少，
  作息规律样本有限").

Only report what the data supports. Write in the user's language (Chinese).
