训练参数

启动训练

训练依赖未安装（需要 torch / transformers / peft）— 启动训练前请先安装：pip install 'deskmate[training]'

训练在本地后台线程运行，期间可能占用较多 CPU/内存。完成后适配器 (LoRA adapter) 会保存到输出目录。

主动提醒 / 推送

DeskMate 根据你的活动规律主动推送的提醒。给出反馈（有用 / 没用）会让推送越来越贴合你，也会成为可训练数据。

我的作息规律
